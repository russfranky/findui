# @findui/kit-paywall-pro

Honest Paywall Kit, by Devon Okafor. A presentational paywall that shows
the total price, the renewal date, and the restore path before the
subscribe action. Sample package generated by the FindUI prototype to
prove the package shape. Status: BUILT as a local folder. It has NOT been
published to npm, and the availability of the @findui npm scope has NOT
been checked or claimed.

## What is in a full FindUI kit package

- Presentational components only (this sample: components/PaywallCard.tsx)
- Design tokens
- The flow graph JSON, where the kit includes a flow
- DESIGN.md, written for agents
- LICENSE and ATTRIBUTION.md
- findui.json, the manifest: creator_id, licence (the FindUI Standard
  Licence), attribution_url, and the metering id that ties use back to
  creator kickback accounting

## Install paths (production design, not live)

- npm mirror: npm install @findui/kit-paywall-pro
- Registry JSON, shadcn style: npx shadcn add https://findui.com/r/paywall-pro
- Canonical page: https://findui.com/designer/devon-okafor/paywall-pro

npm is a free distribution mirror. Kickback metering stays on FindUI's
own registry and API calls. npm download counts are not the payout source.

## Rules this package follows

Published by FindUI automation from a reviewed submission, never by
arbitrary designer code. No install scripts. No arbitrary dependencies.
Versioning is semver, and the kit version is stamped into every FindUI
API payload that returns this kit.
